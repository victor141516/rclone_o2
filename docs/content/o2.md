# O2 Cloud

This is a backend for [O2 Cloud](https://cloud.o2online.es).

The backend follows the API and OAuth flow used by the O2 Cloud Android
application. It is currently experimental: the common file and folder
operations work, but the service does not expose a public rclone-specific API
contract.

Paths are specified as `remote:path`.

Paths may be as deep as required, for example `remote:directory/subdirectory`.

## Configuration

Run:

```console
rclone config
```

Choose `o2` as the storage type.

### SMS login

O2 Cloud does not expose a public rclone-specific login API, so rclone uses the
same OpenID Connect, PKCE, and Mi O2 SMS flow as the Android application. The
authorization requests offline access and returns renewable OAuth credentials.

During `rclone config`, enter the O2 phone number for the account. rclone will
start the login, ask for the SMS verification code, and save the resulting
Android OAuth credentials in the remote configuration.

Access and refresh tokens are obscured before they are saved. The Android
`login/oauth` response also supplies a `validationKey` and `JSESSIONID`; rclone
uses them exactly as the Android client does. Token rotations and renewed SAPI
sessions are applied and saved automatically. These internal values should not
normally be edited.

## Limitations

- By default, file deletes are soft deletes. Removed files are moved to O2
  Cloud's trash and continue to count in the service's trashed quota. Use
  `--o2-use-trash=false` to permanently delete files instead of sending them to
  the trash.
- `purge` soft-deletes the selected folder and its contents.
- Modification times are preserved during upload with one-second precision, but
  cannot currently be set independently after upload.
- Hashes are not available through the observed Android API.
- If the refresh token is revoked, run
  `rclone config reconnect remote:` to authenticate by SMS again.

### Standard options

Here are the Standard options specific to o2 (O2 Cloud).

#### --o2-phone-number

O2 phone number used to receive the login SMS.

Use international format, for example +34600111222, or a Spanish mobile number.

Properties:

- Config:      phone_number
- Env Var:     RCLONE_O2_PHONE_NUMBER
- Type:        string
- Required:    true

### Advanced options

Here are the Advanced options specific to o2 (O2 Cloud).

#### --o2-root-folder-id

Numeric root folder id. Leave blank to discover it from the API.

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_O2_ROOT_FOLDER_ID
- Type:        string
- Required:    false

#### --o2-use-trash

Send files to the trash instead of deleting permanently.

Defaults to true, namely sending files to the trash.
Use `--o2-use-trash=false` to delete files permanently instead.

Properties:

- Config:      use_trash
- Env Var:     RCLONE_O2_USE_TRASH
- Type:        bool
- Default:     true

#### --o2-api-url

O2 Cloud API URL.

Properties:

- Config:      api_url
- Env Var:     RCLONE_O2_API_URL
- Type:        string
- Default:     "https://cloud.o2online.es"

#### --o2-upload-url

O2 Cloud upload API URL.

Properties:

- Config:      upload_url
- Env Var:     RCLONE_O2_UPLOAD_URL
- Type:        string
- Default:     "https://upload.cloud.o2online.es"

#### --o2-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_O2_ENCODING
- Type:        Encoding
- Default:     Slash,Del,Ctl,InvalidUtf8,Dot

#### --o2-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_O2_DESCRIPTION
- Type:        string
- Required:    false
