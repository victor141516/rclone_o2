# O2 Cloud

This is a backend for [O2 Cloud](https://cloud.o2online.es).

The backend was built from the O2 Cloud web application API. It is currently
experimental: the common file and folder operations work, but the service does
not expose a public rclone-specific API contract.

Paths are specified as `remote:path`.

Paths may be as deep as required, for example `remote:directory/subdirectory`.

## Configuration

Run:

```console
rclone config
```

Choose `o2` as the storage type.

### Browser session

O2 Cloud does not expose a public rclone-specific login API. Configure this
backend from an already logged-in browser session:

- `validation_key`: the `validationKey` cookie.
- `jsessionid`: the `JSESSIONID` cookie.
- `device_id`: the browser device id, normally `web-` plus the value of
  `localStorage["omhls.fingerprintKey"]`. If you paste the raw fingerprint
  without `web-`, rclone adds the prefix.

In Chrome/Chromium developer tools, use Application -> Cookies for
`https://cloud.o2online.es` to read the cookies, and Application -> Local
storage for the device id.

Use this only on a machine you trust. These values grant access to the O2 Cloud
account until the web session expires.

## Limitations

- Deletes are soft deletes. Removed files and folders are moved to O2 Cloud's
  trash and continue to count in the service's trashed quota.
- `purge` soft-deletes the selected folder and its contents.
- `DirMove` is not implemented yet.
- Modification times are read from O2 Cloud metadata but cannot currently be set
  independently after upload.
- Hashes are not available through the observed web API.
- Authentication is imported from an existing browser session. rclone does not
  currently perform the Telefonica SMS login flow itself.

### Standard options

Here are the Standard options specific to o2 (O2 Cloud).

#### --o2-validation-key

O2 Cloud validationKey cookie from a logged-in browser session.

Log in at https://cloud.o2online.es/ in your browser, open the developer tools
for cloud.o2online.es, and copy the cookie named validationKey.

**NB** Input to this must be obscured - see [rclone obscure](/commands/rclone_obscure/).

Properties:

- Config:      validation_key
- Env Var:     RCLONE_O2_VALIDATION_KEY
- Type:        string
- Required:    true

#### --o2-jsessionid

O2 Cloud JSESSIONID cookie from the same logged-in browser session.

In browser developer tools, inspect cookies for https://cloud.o2online.es/ and
copy the cookie named JSESSIONID.

**NB** Input to this must be obscured - see [rclone obscure](/commands/rclone_obscure/).

Properties:

- Config:      jsessionid
- Env Var:     RCLONE_O2_JSESSIONID
- Type:        string
- Required:    true

#### --o2-device-id

O2 Cloud web device id from the same logged-in browser session.

In browser developer tools, check local storage for cloud.o2online.es and copy
the value of omhls.fingerprintKey. If the value does not start with web-, rclone
will add that prefix.

Properties:

- Config:      device_id
- Env Var:     RCLONE_O2_DEVICE_ID
- Type:        string
- Required:    true

### Advanced options

Here are the Advanced options specific to o2 (O2 Cloud).

#### --o2-root-folder-id

Numeric root folder id. Leave blank to discover it from the API.

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_O2_ROOT_FOLDER_ID
- Type:        string
- Required:    false

#### --o2-api-url

O2 Cloud API URL.

Properties:

- Config:      api_url
- Env Var:     RCLONE_O2_API_URL
- Type:        string
- Default:     "https://cloud.o2online.es"

#### --o2-upload-url

O2 Cloud upload API URL.

Properties:

- Config:      upload_url
- Env Var:     RCLONE_O2_UPLOAD_URL
- Type:        string
- Default:     "https://upload.cloud.o2online.es"

#### --o2-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_O2_ENCODING
- Type:        Encoding
- Default:     Slash,Del,Ctl,InvalidUtf8,Dot

#### --o2-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_O2_DESCRIPTION
- Type:        string
- Required:    false
