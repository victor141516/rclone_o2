# O2 Cloud

This is a backend for [O2 Cloud](https://cloud.o2online.es).

The backend was built from the O2 Cloud web application API. It is currently
experimental: the common file and folder operations work, but the service does
not expose a public rclone-specific API contract.

Paths are specified as `remote:path`.

Paths may be as deep as required, for example `remote:directory/subdirectory`.

## Configuration

Run:

```console
rclone config
```

Choose `o2` as the storage type.

### SMS login

O2 Cloud does not expose a public rclone-specific login API, so rclone uses the
same Telefonica Mobile Connect SMS flow as the web application.

During `rclone config`, enter the O2 phone number for the account. rclone will
start the login, ask for the SMS verification code, and save the session details
in the remote configuration.

The saved session includes web cookies and a generated web device id. These are
managed automatically and should not normally be edited. If the short-lived web
session expires, rclone will try to renew it using the persistent login cookie,
save the renewed session, and continue the command.

## Limitations

- Deletes are soft deletes. Removed files and folders are moved to O2 Cloud's
  trash and continue to count in the service's trashed quota.
- `purge` soft-deletes the selected folder and its contents.
- `DirMove` is not implemented yet.
- Modification times are read from O2 Cloud metadata but cannot currently be set
  independently after upload.
- Hashes are not available through the observed web API.
- If the persistent login cookie expires or is revoked, run
  `rclone config reconnect remote:` to authenticate by SMS again.

### Standard options

Here are the Standard options specific to o2 (O2 Cloud).

#### --o2-phone-number

O2 phone number used to receive the login SMS.

Use international format, for example +34600111222, or a Spanish mobile number.

Properties:

- Config:      phone_number
- Env Var:     RCLONE_O2_PHONE_NUMBER
- Type:        string
- Required:    true

### Advanced options

Here are the Advanced options specific to o2 (O2 Cloud).

#### --o2-root-folder-id

Numeric root folder id. Leave blank to discover it from the API.

Properties:

- Config:      root_folder_id
- Env Var:     RCLONE_O2_ROOT_FOLDER_ID
- Type:        string
- Required:    false

#### --o2-api-url

O2 Cloud API URL.

Properties:

- Config:      api_url
- Env Var:     RCLONE_O2_API_URL
- Type:        string
- Default:     "https://cloud.o2online.es"

#### --o2-upload-url

O2 Cloud upload API URL.

Properties:

- Config:      upload_url
- Env Var:     RCLONE_O2_UPLOAD_URL
- Type:        string
- Default:     "https://upload.cloud.o2online.es"

#### --o2-refresh-upload-session

Refresh the O2 session before the first upload.

This uses the persistent login cookie to ask O2 for a new session, which may assign a different backend node. Enable this temporarily if uploads are slow and you want to retry with another node.

Properties:

- Config:      refresh_upload_session
- Env Var:     RCLONE_O2_REFRESH_UPLOAD_SESSION
- Type:        bool
- Default:     false

#### --o2-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

Properties:

- Config:      encoding
- Env Var:     RCLONE_O2_ENCODING
- Type:        Encoding
- Default:     Slash,Del,Ctl,InvalidUtf8,Dot

#### --o2-description

Description of the remote.

Properties:

- Config:      description
- Env Var:     RCLONE_O2_DESCRIPTION
- Type:        string
- Required:    false
